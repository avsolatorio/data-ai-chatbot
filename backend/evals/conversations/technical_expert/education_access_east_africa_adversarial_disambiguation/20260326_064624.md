### 1. Primary school enrollment (access) — Ethiopia

**Indicator:** School enrollment, primary (%)  
**Database:** World Bank Global Statistics (WB_GS)  
**Indicator ID:** `WB_GS_SE_PRM_ENRR`  
**Country:** `ETH`  
**Years:** 2015–2024

**Direct API URL:**

```text
https://data360api.worldbank.org/data360/data?DATABASE_ID=WB_GS&INDICATOR=WB_GS_SE_PRM_ENRR&REF_AREA=ETH&timePeriodFrom=2015&timePeriodTo=2024&SEX=_T&top=1000
```

**Python example (requests):**

```python
import requests

url = "https://data360api.worldbank.org/data360/data"
params = {
    "DATABASE_ID": "WB_GS",
    "INDICATOR": "WB_GS_SE_PRM_ENRR",
    "REF_AREA": "ETH",
    "timePeriodFrom": 2015,
    "timePeriodTo": 2024,
    "SEX": "_T",   # total (both sexes)
    "top": 1000
}

r = requests.get(url, params=params)
data = r.json()["data"]  # list of records with TIME_PERIOD, REF_AREA, OBS_VALUE, claim_id, etc.
```

## Analysis

- Use **`REF_AREA=ETH`** for Ethiopia in all queries.
- For sex-disaggregated indicators (where `SEX` is a dimension), you can request:
  - `SEX=_T` for totals (as above),
  - or `SEX=F` / `SEX=M` if you need female/male series (check disaggregation options first if you want to be strict).
- Response objects will include:
  - `TIME_PERIOD`, `REF_AREA`, `OBS_VALUE`, and a `claim_id` you must keep if you plan to use Data360’s claim-tagging downstream.
- For “Abyssinia” in your upstream data, normalize to:
  - Country name: **Ethiopia**
  - Code: **ETH**
  - Then call the APIs as shown.
