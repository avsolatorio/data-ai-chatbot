## 1. World Bank – World Development Indicators (WDI)

**What it’s good for:** Long-run, internationally comparable series on poverty, inequality, growth, social indicators.

### Key India poverty/inequality indicators

- Poverty headcount ratio at $2.15 a day (2017 PPP) (% of population) – `SI.POV.DDAY`
- Poverty headcount ratio at $3.65 a day (2017 PPP) (% of population) – `SI.POV.LMIC`
- Poverty headcount ratio at $6.85 a day (2017 PPP) (% of population) – `SI.POV.UMIC`
- Gini index – `SI.POV.GINI`
- Income share held by lowest 10% – `SI.DST.10TH.10`
- Income share held by highest 10% – `SI.DST.10TH.10` (check metadata; there are several distribution indicators)
- Income share held by lowest 20% – `SI.DST.02ND.20`
- Income share held by highest 20% – `SI.DST.05TH.20`

Country code for India: `IND`.

### Web interface (downloadable files)

- Main portal:  
  https://databank.worldbank.org/source/world-development-indicators

From there you can:

- Select “India” as country
- Add the indicators above
- Download as:
  - CSV
  - Excel (XLSX)
  - XML

### API access

Base API docs:  
https://datahelpdesk.worldbank.org/knowledgebase/topics/125589-developer-information

**General pattern:**

```text
https://api.worldbank.org/v2/country/{country_code}/indicator/{indicator}?format=json&per_page=2000
```

**Examples for India:**

- Gini index for India:

  ```text
  https://api.worldbank.org/v2/country/IND/indicator/SI.POV.GINI?format=json&per_page=2000
  ```

- Poverty headcount at $2.15/day (2017 PPP):

  ```text
  https://api.worldbank.org/v2/country/IND/indicator/SI.POV.DDAY?format=json&per_page=2000
  ```

You can change `format=` to:

- `json` – JSON (easy for scripts)
- `xml` – XML

## 2. World Bank – PovcalNet (Global Poverty Monitoring)

**What it’s good for:** Official World Bank global poverty estimates and micro-based distributions; more detailed than WDI for poverty.

### Web interface

- PovcalNet online tool:

It allows you to:

- Select India
- Choose poverty lines (e.g., $2.15, $3.65, $6.85)
- Get headcount ratios, gaps, mean income, etc.
- Download outputs as CSV or Excel.

### API access

API documentation:  
https://www.worldbank.org/en/research/brief/povcalnet-api

Typical API structure (GET):

```text
https://api.worldbank.org/povcalnet/povcalnet?country=IND&povertyline=2.15&year=all&format=json
```

Parameters:

- `country=IND`
- `povertyline=2.15` (or 3.65, 6.85, etc.)
- `year=all` or a specific year
- `format=json` or `csv`

**Example for all years, India, $2.15/day:**

```text
https://api.worldbank.org/povcalnet/povcalnet?country=IND&povertyline=2.15&year=all&format=csv
```

This returns a CSV you can download or feed directly into your workflow.

**Citation example:**

> World Bank. PovcalNet: the online tool for poverty measurement. India, poverty line $2.15 (2017 PPP). Accessed [date].

https://datahelpdesk.worldbank.org/knowledgebase/topics/125589-developer-information

**General pattern:**

```text
https://api.worldbank.org/v2/country/{country_code}/indicator/{indicator}?format=json&per_page=2000
```

**Examples for India:**

- Gini index for India:

  ```text
  https://api.worldbank.org/v2/country/IND/indicator/SI.POV.GINI?format=json&per_page=2000
  ```

- Poverty headcount at $2.15/day (2017 PPP):

  ```text
  https://api.worldbank.org/v2/country/IND/indicator/SI.POV.DDAY?format=json&per_page=2000
  ```

You can change `format=` to:

- `json` – JSON (easy for scripts)
- `xml` – XML

**Quick Python example:**

```python
import requests

url = "https://api.worldbank.org/v2/country/IND/indicator/SI.POV.DDAY"
params = {"format": "json", "per_page": 2000}
r = requests.get(url, params=params)
data = r.json()
```

**Citation format (example):**

> World Bank. World Development Indicators. “Poverty headcount ratio at $2.15 a day (2017 PPP) (% of population) [SI.POV.DDAY].” Accessed [date].

## 2. World Bank – PovcalNet (Global Poverty Monitoring)

**What it’s good for:** Official World Bank global poverty estimates and micro-based distributions; more detailed than WDI for poverty.

It allows you to:

- Select India

https://api.worldbank.org/povcalnet/povcalnet?country=IND&povertyline=2.15&year=all&format=json

Parameters:

- `country=IND`
- `povertyline=2.15` (or 3.65, 6.85, etc.)
- `year=all` or a specific year
- `format=json` or `csv`

**Example for all years, India, $2.15/day:**

```text
https://api.worldbank.org/povcalnet/povcalnet?country=IND&povertyline=2.15&year=all&format=csv
```

This returns a CSV you can download or feed directly into your workflow.

## 4. World Inequality Database (WID)

### Web interface

  https://wid.world
- Country page for India:

You can interactively select:

- Wealth inequality
- Gini coefficients
- Time series

And download:

- CSV
- Excel

Basic API endpoint pattern:

```text

```

For India, the “area” code is usually `in` or `IND` depending on the series; WID’s documentation gives the exact codes. Example pattern:

```text
https://wid.world/data/api/shweal999i/in/?downloadformat=csv
```

Where:

- `shweal999i` – indicator code (e.g., share of wealth held by top 10%)
- `in` – India
- `downloadformat=csv` or `xlsx`

You’ll need to look up the exact indicator codes in their docs/interface for the specific series you need (top 1% income share, etc.).

> World Inequality Database (WID). “Distribution of national income and wealth – India.” Accessed [date].

From these pages you can:

- Often download data tables in Excel/CSV

### API / machine-readable access

- Open Government Data (OGD) Platform India:

Search for “poverty,” “consumption,” “NSS,” or “PLFS.” Many datasets are downloadable as:

- CSV
- JSON
- XML
- Excel

Each dataset page typically provides:

- JSON API endpoint (with query parameters for filters).

You’ll need to register for a (free) API key on data.gov.in.
