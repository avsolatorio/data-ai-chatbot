### 2. Convert to pandas DataFrames and normalize

The Data360 API response structure is typically like:

```json
{
  "data": [
    {
      "TIME_PERIOD": "2020",
      "REF_AREA": "BRA",
      "OBS_VALUE": 1234567890.0,
      "UNIT_MEASURE": "USD",
      "claim_id": "abcd1234",
      ...
    },
    ...
  ],
  "metadata": { ... }
}
```

You can normalize this into DataFrames and then merge:

```python
import pandas as pd

def to_df(payload: dict) -> pd.DataFrame:
    # "data" is the list of observations
    records = payload.get("data", [])
    if not records:
        return pd.DataFrame()
    df = pd.DataFrame.from_records(records)
    # Standardize column names if needed
    df.rename(columns={
        "TIME_PERIOD": "year",
        "REF_AREA": "country",
        "OBS_VALUE": "value"
    }, inplace=True)
    # Convert year to int where possible
    df["year"] = df["year"].astype(int)
    return df

gdp_df = to_df(gdp_json)
health_df = to_df(health_json)

# Add more descriptive column names
gdp_df.rename(columns={"value": "gdp_current_usd"}, inplace=True)
health_df.rename(columns={"value": "health_exp_pct_gdp"}, inplace=True)
```

At this point:

- `gdp_df` has columns like: `year`, `country`, `gdp_current_usd`, `UNIT_MEASURE`, `claim_id`, etc.
- `health_df` has: `year`, `country`, `health_exp_pct_gdp`, `UNIT_MEASURE`, `claim_id`, etc.

### 3. Merge GDP and health data for Brazil & Mexico

```python
# Keep only the essential columns plus claim_id if you want traceability
gdp_keep = ["year", "country", "gdp_current_usd", "claim_id"]
health_keep = ["year", "country", "health_exp_pct_gdp", "claim_id"]

gdp_df = gdp_df[gdp_keep].rename(columns={"claim_id": "gdp_claim_id"})
health_df = health_df[health_keep].rename(columns={"claim_id": "health_claim_id"})

merged = (
    gdp_df
    .merge(health_df, on=["country", "year"], how="inner")
    .sort_values(["country", "year"])
)

print(merged.head())
```

You now have a tidy panel dataset of `country`–`year` with both GDP and health expenditure (% of GDP) plus the original **claim IDs** for validation back to the underlying observations.

```python
def validate_units(df: pd.DataFrame, expected_unit: str):
    units = set(df.get("UNIT_MEASURE", []))
    if units and units != {expected_unit}:
        raise ValueError(f"Unexpected UNIT_MEASURE values: {units} (expected {expected_unit})")
```
