## Direct API Access (integration pattern)

All Data360 API URLs share a common structure:

`https://data360api.worldbank.org/data360/data?DATABASE_ID=...&INDICATOR=...&REF_AREA=...&timePeriodFrom=YYYY&timePeriodTo=YYYY&top=...`

**Python example (you can swap indicator and database IDs as needed):**

```python
import requests
import pandas as pd

base_url = "https://data360api.worldbank.org/data360/data"

params = {
    "DATABASE_ID": "WB_WDI",
    "INDICATOR": "WB_WDI_GC_DOD_TOTL_GD_ZS",  # central gov debt, % of GDP
    "REF_AREA": "GHA,NGA,SEN,CIV,MLI,BFA,NER,TGO,BEN,SLE,LBR,GIN,CPV,GMB",
    "timePeriodFrom": 2010,
    "timePeriodTo": 2025,
    "top": 14000
}

r = requests.get(base_url, params=params)
r.raise_for_status()
json_data = r.json()

# Data360 returns a 'data' list with TIME_PERIOD, REF_AREA, OBS_VALUE, claim_id, etc.
records = json_data["data"]
df = pd.DataFrame(records)

# Example: pivot to have years as rows and countries as columns
pivot = df.pivot(index="TIME_PERIOD", columns="REF_AREA", values="OBS_VALUE")
print(pivot.head())
```

You can use the same pattern in R (`httr` + `jsonlite`), Stata (`import delimited` from the CSV links), or Power BI (web connector to the API URL).

## Analysis (how to use these succinctly in your briefing)

For a concise briefing on **West Africa fiscal sustainability**, you can structure the narrative around:

1. **Debt levels vs GDP**  
   - Use **WEO general government debt (% of GDP)** for IMF‑consistent numbers and projections.  
   - Cross‑check with **WDI central government debt** and **CCDFS general government debt** when you want methodological robustness or fiscal‑space framing.

2. **Debt vs fiscal capacity**  
   - Combine **debt‑to‑GDP** with **revenue‑to‑GDP** to highlight countries with **high debt and low revenue** (e.g., high debt‑to‑revenue ratios).

3. **Debt service burden and external risk**  
   - Use **external debt stocks (US$)** and **interest payments on external debt** to show:  
     - Rising external leverage.  
     - Increasing interest bills, especially where market borrowing has grown.  
   - If needed, you can derive **interest‑to‑exports** and **interest‑to‑revenue** indicators from these series plus WDI exports and revenue data.

4. **Methodological caveats (one‑liner per source)**  
   - **WDI fiscal indicators:** Mostly **central government**, not full general government; some countries only have budgetary central government.  
   - **IMF WEO:** Model‑based estimates and projections; subject to revision but best for forward‑looking debt paths.  
   - **CCDFS:** Research dataset; very useful for fiscal‑space analysis, but not an official surveillance database.  
   - **IDS/WDI external debt:** Focused on **public and publicly guaranteed** plus some private debt; quality depends on debtor reporting.

You can keep these caveats in a short “data notes” box in the briefing.
