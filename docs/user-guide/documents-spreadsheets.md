# Documents and Spreadsheets

Data360 Chat can create and edit documents in real time. Documents appear in a side panel so you can see your content update as the AI works.

---

## Supported document types

- **Text documents** — Articles, emails, reports
- **Code files** — With syntax highlighting for multiple languages
- **Spreadsheets** — Data tables and structured information

---

## Creating a document

1. Ask the AI to create a document, for example:
   - "Create a report about climate change impacts"
   - "Write a Python script to analyze sales data"
   - "Create a spreadsheet with monthly budget categories"
2. The AI will generate the content and display it in the side panel.
3. You can view, edit, and copy the content from the panel.

---

## Editing a document

1. Ask the AI to modify the document, for example:
   - "Add a section about recommendations"
   - "Fix the bug in the Python script"
   - "Add a new row to the spreadsheet"
2. The changes will appear in the side panel in real time.

---

## Side panel

The document side panel shows the current document. You can:

- Scroll to view the full content
- Copy text or code to your clipboard
- Expand or collapse the panel to focus on the chat or the document
